# 📊 Strategic Sales Dashboard

This folder contains the Power BI visualisations for the Regional Sales Analysis (2022–2026). The dashboard translates EDA findings and the Seasonal Naïve forecast into actionable business insights across 4 pages.

## 📂 Files

- `Regional_Sales_Analysis_dashboard.pbix` — Power BI Desktop file for editing
- `Regional_Sales_Analysis_Dashboard.pdf` — Static export for quick viewing without Power BI

---

## 📄 Dashboard Pages

**Page 1 — Overview**
KPI cards + top 10 products by revenue + revenue share donut.
Key numbers: $1.24B total revenue · 175 customers · 30 products · Product 26 leads at $117.3M

**Page 2 — Regional Analysis**
State bar chart + US map + region breakdown + treemap.
Key numbers: California 18.5% ($228.8M) · West leads at $372.1M · Top 5 states = 57% of revenue

**Page 3 — Monthly Trends**
Year slicer + monthly revenue line + seasonality bar chart + avg unit price line.
Key finding: January volume-driven peak · April consistent trough · -1.43% YoY decline in 2025

**Page 4 — 2026 Forecast**
Forecast vs budget cards + monthly comparison lines + cumulative gap chart + monthly shortfall bars.
Key numbers: $289.6M forecast · $318.6M target · -$28.96M gap (-9.1%) · Model accuracy 97.8%

---

## 🔗 Data Source

All pages connect live to `v_master_sales_report` in MySQL (`sales_hybrid_db`).
The 2026 Forecast page additionally reads from `07_results/Forecast_2026.csv` generated by `05_notebooks/05_Seasonal_Naaive_Forecast.ipynb`.

To refresh: open the `.pbix` file → Home → Refresh (MySQL must be running locally).
